DESCRIPCIÓN GENERAL


Desarrollo de una plataforma web profesional orientada a la venta automatizada de servicios fotográficos. Incluye página principal, landings especializadas por categoría, sistema de reservas con calendario, pasarela de pago integrada y chatbot de atención al cliente. El objetivo es que el negocio funcione de forma autónoma: el cliente reserva, paga y el fotógrafo recibe un resumen limpio con fecha, hora y datos del cliente.
